## Cara memakai notebook

1. Buka Google Colab, pilih **File > Upload notebook**, lalu pilih berkas `.ipynb` dari folder pertemuan.
2. Data **tidak ditanam di dalam notebook**. Unggah sendiri berkas data yang diminta di sel awal notebook (dari dosen atau dari folder `data/`).
3. Jalankan sel secara berurutan dan kerjakan bagian latihan mandiri.

## Catatan

- Dataset di folder `data/` adalah data sintetis (rekaan) dan tidak berisi data mahasiswa sebenarnya.
- Dataset kuesioner kelas, nilai, dan berkas penilaian dosen tidak disertakan di repositori ini.
